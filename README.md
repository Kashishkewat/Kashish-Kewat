Supervised NLP model that classifies SMS messages as spam or not spam.

- Text preprocessing and TF-IDF vectorization
- Naive Bayes classification
- Evaluated with accuracy, precision and recall

### 📚 [Book Recommender System](https://github.com/Kashishkewat/book_recommender_system)

Personalized book recommendations using collaborative filtering.

- Built a user-item matrix from 1M+ rating records
- K-Nearest Neighbors model to find similar users and books
- Recommends books based on user rating similarity
